youvision/think-store-admin · dev-main

权限认证总览

查看规则、角色、用户关系与当前配置。本页为静态文档，运行时页面由包内 View 渲染， layui 静态资源通过 assets 路由输出，无需发布到宿主 public 目录。

认证服务已注册 layui 2.13.9 只读总览
4 认证数据表
3 主题路由
3 CLI 命令
RBAC 规则 / 角色授权模型
用户权限查询 只读
默认仅可查询当前登录用户。需要查看其他用户时，请在 config/store_admin.php 配置 theme_permission，并由拥有该规则的用户操作。该接口不修改任何权限数据。
接口地址 /store/think-store-admin/api/user?uid=1
请求方式 GET
返回内容 用户拥有的规则、角色及角色 ID，只读
失败响应 未登录或越权返回 403，未提供 uid 返回 422，查询异常返回 500

  "code": 0,
  "msg": "ok",
  "data": {
    "uid": 1,
    "rules": ["Admin/User/Index"],
    "roles": [{"role_id": 1, "role": {"title": "管理员", "status": 1}}],
    "role_ids": [1]
  }
}

总览页地址 /store/think-store-admin/index
认证数据表
store_admin_rule 权限规则 规则标识、类型、状态与条件表达式
store_admin_role 权限角色 角色名称与启用状态
store_admin_role_user 用户角色关系 用户与角色的多对多关联
store_admin_role_rule 角色规则关系 角色与规则的关联，决定角色权限

表名会自动拼接数据库配置中的前缀。执行 php think store:admin:install 创建数据表。
